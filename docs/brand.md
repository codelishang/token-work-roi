# 元衡品牌说明

![元衡 Token Work ROI](../public/yuanheng-logo.svg)

## 名称

- 中文名：**元衡**
- 英文名：**Token Work ROI**
- 命令名：`token-work`

“元”取自词元，也包含成本和原始记录的含义；“衡”表示衡量、校准和取舍。名称表达的是同一件事：把 AI 编程中的token用量、费用和产出放到统一口径下复盘。

英文名直接说明产品用途。Token Work 指 AI 编程产生的 token 用量和工作记录，ROI 指投入产出复盘，不表示财务收益承诺。

## Logo

Logo 由本项目独立绘制，源文件保存在仓库中，没有使用第三方 Logo、角色形象或素材模板。

图形与实际文件对应：

- 深色圆角底形用于承载图标，在 Web、桌面和小尺寸场景保持清晰。
- 米白色上弧、左右内弧、下弧和中轴组成“衡量”的结构，中轴表示统一统计口径。
- 横向彩色曲线表示用量、成本和产出随时间变化；中间圆点表示一次校准或复盘节点。
- 横版 Logo 使用“元衡”和“TOKEN WORK ROI”，下方说明项目的核心用途。

## 使用规范

- 保持原始比例和颜色，不拉伸、不旋转、不重新描边。
- 图标周围至少保留图标宽度 10% 的留白。
- 小尺寸位置使用图标文件，横向空间充足时使用横版 Logo。
- 不把第三方品牌图形并入 Logo，也不添加阴影、立体高光或装饰文字。
- “元衡”“Token Work ROI”和 Logo 应作为同一项目标识使用，不随意组合其他英文缩写。
