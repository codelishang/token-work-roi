# 2026-08-18

## 新增 WorkBuddy 采集器

为元衡（Token Work ROI）项目新增 WorkBuddy 实验采集器，支持从 `~/.workbuddy/traces/` 解析 trace 文件中的 token 用量数据。

### 变更文件
- `src/collectors/workbuddy.ts` — 新建采集器模块，解析 trace JSON 中的 generation span 的 toolOutput，提取 OpenAI 兼容的 usage 数据
- `src/collector-registry.ts` — 注册 workbuddy 为 stableCollector（隐私级别 metadata-only，根目录 ~/.workbuddy/traces）
- `src/collector-config.ts` — 新增 `resetConfigCache()` 导出，用于测试中清除配置缓存
- `config/collectors.json` — 添加 workbuddy 配置项（tracesDir, sessionsDir, root）
- `test/workbuddy-collector.test.ts` — 9 个测试用例覆盖解析、多 span、缺失数据、审计等场景
- `test/fixtures/collectors/workbuddy/` — 测试 fixture（trace 文件 + session 文件）
- `test/experimental-collectors.test.ts` — 更新 CLI 审计测试以适配新增的实验采集器
- `docs/collector-support-matrix.md` — 添加 WorkBuddy 行
- `docs/local-collectors.md` — 添加 WorkBuddy 实验来源说明
- `README.md` / `README.en.md` — 数据来源表添加 WorkBuddy
- `CHANGELOG.md` — 2.0.0 添加 WorkBuddy 条目

### 技术要点
- WorkBuddy trace 文件路径：`~/.workbuddy/traces/<pid>/trace_*.json`
- Session 映射文件：`~/.workbuddy/sessions/<pid>.json`（包含 sessionId 和 cwd）
- token 语义：prompt_tokens 是 cache-inclusive（OpenAI 惯例），采集器减去 cached_tokens 得到净输入
- 采集器导出 `collect()`, `collectWithAudit()`, `audit()` 三个函数
- 真机 dry-run 验证通过：1 个 trace 文件，517 tokens，coverage=trusted-event-level
